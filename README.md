# PeopleDesk — Employee Management System

This repository contains the complete starter project archive, including the React/Vite frontend, Node.js/Express API, PostgreSQL configuration, JWT/RBAC starter, optional AI chatbot, Docker Compose setup, and project documentation.

## Get the source
Download `employee-management-system-project.zip` from this repository and extract it. The archive contains the full `ems-project/` directory with source code and docs.

## Local setup
1. Extract the ZIP.
2. Copy `.env.example` to `.env` and replace all placeholder secrets.
3. From the `ems-project` directory, run `docker compose up --build`.
4. Open `http://localhost:5173`; health check: `http://localhost:5000/api/health`.

See `docs/PROJECT_GUIDE.md` and `docs/ARCHITECTURE.md` inside the extracted project for setup details and workflow diagrams.

> Learning starter only—not production-ready. Do not use real HR data before a security review. AWS resources have not been provisioned. Cloud services and AI API usage may incur charges.
